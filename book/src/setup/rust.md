# Installation (Rust)

Before using Oxicord, you need to install Rust. If you already have it, you can skip to the next chapter. If you're new to Rust, read this.

## Rustup

Install rustup (<https://rustup.rs>) which will install Rust and Cargo (the Rust package manager).

When installed, start a new terminal and run these commands to confirm that the installations worked.

```sh
rustc --version
cargo --version
```

## Initialize a project

You can initialize a project with Cargo:

```sh
cargo new my_bot
```

This will create a `my_bot` project folder.
